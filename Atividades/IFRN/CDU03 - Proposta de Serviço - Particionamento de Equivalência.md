# Planejar os testes funcionais: elaborar os casos de teste para os principais CDUs do projeto PDS

## Proposta de Serviço: Particionamento de Equivalência

| Variáveis de Entrada          | Condições               | Classes de Equivalência (Válidas)                                         | Classes de Equivalência (Inválidas)                       |
| ----------------------------- | ----------------------- | ------------------------------------------------------------------------- | --------------------------------------------------------- |
| Nome (Razão Social)           | Comprimento             | 1. 3–255 caracteres                                                       | 2. < 3 caracteres (inclui vazio) <br> 3. > 255 caracteres |
| Descrição                     | Preenchimento           | 4. Qualquer tamanho válido (inclui textos longos)                         | 5. Nulo                                                   |
| CNPJ (Formato)                | Estrutura               | 6. 14 dígitos numéricos                                                   | 7. Tamanho ≠ 14 <br> 8. Caracteres inválidos              |
| Preço Mínimo                  | Valor e tipo            | 9. Numérico > 0                                                           | 10. ≤ 0 <br> 11. Tipo inválido                            |
| Preço Máximo                  | Relação com mínimo      | 12. ≥ Preço Mínimo                                                        | 13. < Preço Mínimo <br> 14. ≤ 0                           |
| Capacidade Máxima             | Tipo e valor            | 15. Inteiro > 0 <br> 16. Nulo (opcional)                                  | 17. ≤ 0 <br> 18. Decimal                                  |
| CEP                           | Formato                 | 19. 8 dígitos numéricos                                                   | 20. Tamanho ≠ 8 <br> 21. Caracteres inválidos             |
| Logradouro                    | Comprimento             | 22. ≥ 5 caracteres                                                        | 23. < 5 caracteres                                        |
| Número                        | Preenchimento           | 24. Número ou "S/N"                                                       | 25. Vazio                                                 |
| Cidade (FK)                   | Existência              | 26. ID existente                                                          | 27. Inexistente <br> 28. Nulo                             |
| Estado                        | Consistência            | 29. Coerente com cidade                                                   | 30. Inconsistente com cidade                              |
| Categoria (FK)                | Existência              | 31. ID existente                                                          | 32. Inexistente <br> 33. Nulo                             |
| Tags                          | Opcionalidade e relação | 34. Lista válida (pertencente à categoria) <br> 35. Nulo/Vazio (opcional) | 36. Tag de outra categoria <br> 37. Tag inexistente       |
| Horário (Abertura/Fechamento) | Regra temporal          | 38. Fechamento > Abertura                                                 | 39. Fechamento ≤ Abertura <br> 40. Formato inválido       |
| Dias da Semana                | Unicidade               | 41. Dias únicos                                                           | 42. Duplicados                                            |
| Fotos do Negócio              | Presença e tipo         | 43. ≥ 1 imagem válida (PNG/JPG)                                           | 44. Sem foto de capa <br> 45. Tipo inválido               |
